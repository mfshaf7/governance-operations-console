# Source Graduation

This directory records the reviewed transfer of the approved Governance
Operations Console baseline from Workspace Prototype Studio into this durable
product repository.

The graduation boundary includes:

- the exact approved application source
- product-local architecture and design records
- public-source exclusions
- path and ownership adaptations required by the new repository root
- local validation and baseline-equivalence evidence

It does not include live backend wiring, shared runtime activation, identity,
deployment, governed release, or new security acceptance.

The source provenance is machine-readable in
[`source-manifest.json`](source-manifest.json). The approved Prototype Studio
baseline record is retained in
[`approved-design-baseline.yaml`](approved-design-baseline.yaml).
